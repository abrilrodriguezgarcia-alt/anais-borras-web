# Imatges

Aquesta carpeta contindrà els assets fotogràfics del projecte.

## Asset prioritari

### `anais-hero.jpg`

Foto real aprovada per al hero:
- Anaïs sobre fons lavanda,
- vestida de negre,
- composició horitzontal a partir de la fotografia vertical aportada,
- mirada cap al costat esquerre de la pantalla.

No substituir aquesta fotografia per stock o generació IA.

## Convencions

- Originals de qualitat suficient.
- Generar versions optimitzades WebP/AVIF durant el build o preparació.
- Mantenir una còpia JPG/PNG només quan calgui.
- Noms descriptius en minúscules i kebab-case.
- Afegir sempre alt text des del codi, no al nom de fitxer.
